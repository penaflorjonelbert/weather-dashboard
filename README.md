# Weather Dashboard 🌤️

A simple Weather Dashboard created using HTML, CSS, and JavaScript.

## Features

- Search for a city
- Display temperature
- Show weather conditions
- Display humidity
- Display wind speed
- Sample weather data for different cities

## Available Cities

- Manila
- Cebu
- Davao

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

This project was created to practice basic web development and JavaScript programming.
